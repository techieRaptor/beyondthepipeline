# BeyondThePipeline — V1 Premium

A content-first engineering publication and portfolio built with Next.js, React, TypeScript, Tailwind CSS, and MDX.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## V1 scope

- Premium dark engineering visual system
- Responsive header/navigation
- Technical hero visual
- Latest article cards
- Featured project cards
- About / Contact pages
- MDX article rendering
- SEO metadata, sitemap and robots
- Frontend-only newsletter CTA

No database, auth, CMS, AI assistant, SQL playground backend, payments, or newsletter backend are included in V1.
